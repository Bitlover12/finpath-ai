# FinPath Frontend

Next.js + TypeScript + Tailwind CSS frontend skeleton.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Environment

Copy `.env.example` to `.env.local` when API integration begins.

```text
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000
```

STEP 1 does not call the backend yet.
